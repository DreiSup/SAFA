========================================
  ORDEN DE ARRANQUE RECOMENDADO
========================================

1. docker-compose up -d
2. cd backend && source venv/bin/activate && python run.py          # Flask + APScheduler (candles automáticos)
3. cd backend && source venv/bin/activate && python -m app.services.producer_news
4. cd backend && source venv/bin/activate && python -m app.services.producer_reddit
5. cd backend && source venv/bin/activate && python -m app.schemas.consumer_spark
6. cd backend && source venv/bin/activate && python -m app.services.encoding_worker
7. cd backend && source venv/bin/activate && python -m app.services.crypto.producer_binance_ws
8. cd backend && source venv/bin/activate && python -m app.services.stocks.producer_alpaca     # solo en horario de mercado (L-V 15:30-22:00 CET)
9. cd frontend && npm run dev

========================================
  SAFA — SHORTCUTS DE EJECUCIÓN
========================================

  Todos los comandos se ejecutan desde la raíz del proyecto (/SAFA)
  salvo que se indique lo contrario.

  IMPORTANTE: activar el entorno virtual antes de cualquier comando de backend:
    cd backend && source venv/bin/activate

  ----------------------------------------
    INFRAESTRUCTURA (Docker)
  ----------------------------------------

  Levantar Kafka + Zookeeper:
    docker-compose up -d

  Parar Kafka + Zookeeper:
    docker-compose down

  Ver logs de los contenedores:
    docker-compose logs -f

  ----------------------------------------
    BACKEND
  ----------------------------------------

  Iniciar servidor Flask (incluye APScheduler con candles automáticos):
    cd backend && source venv/bin/activate && python run.py

  Productor de noticias (NewsAPI → Kafka: news_ticker):
    cd backend && source venv/bin/activate && python -m app.services.producer_news

  Productor de Reddit (Reddit → Kafka: reddit_ticker):
    cd backend && source venv/bin/activate && python -m app.services.producer_reddit

  Consumer Spark + FinBERT (Kafka: news_ticker + reddit_ticker → MongoDB):
    cd backend && source venv/bin/activate && python -m app.schemas.consumer_spark

  Encoding worker (MongoDB → Qdrant, polling cada 30s):
    cd backend && source venv/bin/activate && python -m app.services.encoding_worker

  Productor BTC WebSocket (Binance WS → Kafka: crypto_prices):
    cd backend && source venv/bin/activate && python -m app.services.crypto.producer_binance_ws

  Productor SP500 WebSocket (Alpaca WS → Kafka: stock_prices) [solo L-V 15:30-22:00 CET]:
    cd backend && source venv/bin/activate && python -m app.services.stocks.producer_alpaca

  ----------------------------------------
    SCRIPTS (one-shot)
  ----------------------------------------

  Seed histórico de crypto en MongoDB:
    cd backend && source venv/bin/activate && python -m app.scripts.seed_crypto_history

  Seed histórico de SP500 en MongoDB:
    cd backend && source venv/bin/activate && python -m app.scripts.seed_sp500_history

  Descargar modelo FinBERT localmente:
    cd backend && source venv/bin/activate && python -m app.scripts.download_finbert

  ----------------------------------------
    FRONTEND
  ----------------------------------------

  Iniciar React en modo desarrollo:
    cd frontend && npm run dev
